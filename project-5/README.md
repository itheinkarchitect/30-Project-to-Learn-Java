# Консольный менеджер задач

Пятый проект из серии **30 проектов для изучения Java**.

## О проекте

Простой консольный To-Do List, позволяющий создавать, просматривать, выполнять и удалять задачи.

## Изучил

* Классы и объекты
* Конструкторы и `this`
* Методы классов
* Основы ООП
* `ArrayList`
* `for-each`
* `Scanner`
* `switch`
* Разделение программы на несколько классов

## Запуск

```bash
javac -encoding UTF-8 Main.java Task.java TaskManager.java
java -Dfile.encoding=UTF-8 Main
```

Проект создан в рамках моего обучения Java.
