# Unit Converter

Консольный конвертер единиц на Java.

## Возможности

* 📏 Длина: метры, километры, сантиметры
* ⚖️ Масса: граммы, килограммы, тонны
* 🌡️ Температура: Цельсий, Фаренгейт, Кельвин
* ⏱️ Время: секунды, минуты, часы

## Изученные темы

В проекте используются:

* `methods`
* `switch`
* `enum`
* `Scanner`
* `double`
* преобразования типов
* работа с несколькими категориями и единицами измерения

## Запуск

```bash
javac UnitConverter.java
java UnitConverter
```
