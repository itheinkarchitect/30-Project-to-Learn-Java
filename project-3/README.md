# 🎯 Guess Number

Консольная игра на Java, в которой программа загадывает случайное число от 1 до 100, а пользователь пытается его угадать.

## 📚 Что изучил

* `while` — циклы
* `if / else if / else` — условия
* `Random` — генерация случайных чисел
* `Scanner` — обработка пользовательского ввода
* Подсчёт количества попыток

## 🚀 Запуск

```bash
javac GuessNumber.java
java GuessNumber
```

## 🎮 Как играть

Программа загадывает число от 1 до 100 и подсказывает:

* **«Больше»** — загаданное число больше введённого.
* **«Меньше»** — загаданное число меньше введённого.
* **«Поздравляю!»** — число угадано.
