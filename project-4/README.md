# Textalyzer

Консольный анализатор текста на Java.

## Возможности

* Подсчёт длины текста
* Определение первого и последнего символа
* Перевод текста в верхний и нижний регистр
* Проверка наличия слова
* Подсчёт количества слов
* Поиск самого длинного слова
* Подсчёт гласных
* Эффект постепенной печати текста

## Изучено

* `String`
* Массивы `String[]`
* Циклы и условия
* Методы
* `StringBuilder`
* `Thread.sleep()`
* Обработка `InterruptedException`
