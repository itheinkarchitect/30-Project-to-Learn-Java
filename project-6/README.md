# Banking System

Учебный банковский менеджер на Java.

## Возможности

* Создание клиентов
* Создание банковских счетов
* Пополнение и снятие средств
* Перевод денег между счетами
* Просмотр информации о счёте

## Изучено

* Классы и объекты
* Инкапсуляция
* Композиция
* `ArrayList`
* Взаимодействие объектов
* Работа с `boolean` и `null`
* Консольный интерфейс

## Запуск

```bash
javac *.java
java Main
```
