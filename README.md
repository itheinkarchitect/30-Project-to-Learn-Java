# ☕ 30 проектов — Java

Мой учебный путь по изучению **Java** от базового синтаксиса до уровня **Junior Java Developer**.

Этот репозиторий представляет собой серию из **30 практических проектов**, каждый из которых посвящён определённым технологиям и концепциям Java.

Главная цель — не просто изучить синтаксис языка, а научиться применять Java для создания полноценных приложений и backend-систем.

---

## 🎯 Цель

Пройти путь:

**Java Syntax → OOP → Collections → Files → Multithreading → SQL → Spring Boot → REST API → Security → Docker → Microservices → Junior**

Каждый новый проект должен быть сложнее предыдущего и знакомить меня с новыми инструментами и подходами разработки.

# 🏆 Система оценки

Каждый проект оценивается по десятибалльной шкале.

Оцениваются:

* работоспособность;
* архитектура;
* качество кода;
* использование возможностей Java;
* обработка ошибок;
* дополнительные возможности;
* читаемость кода и документации.

После завершения всех 30 проектов будет подсчитан общий результат:

**30 проектов × 10 баллов = 300 баллов**

Также будет оцениваться не только итоговый результат, но и прогресс от первого проекта до последнего.
